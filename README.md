# Страница блога

Данное приложение, написанное на React, позволяет редактировать страницу блога с помощью сайдбара.

---

## 🛠️ Используемые технологии

| Технология | Версия |
|------------|--------|
| **React**  | 18.x   |
| **TypeScript** | 5.x |
| **Webpack**   | 5.x    |
| **clsx**   | 2.x   |
| **ESLint + Prettier** |
| **Storybook** | 7.6.x |

---

## 🚀 Как запустить проект

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Ascens1ve/blog-customizer.git
cd blog-customizer
```

### 2. Установите зависимости
```bash
npm install
```

### 3. Запустите в режиме разработки
```bash
# Webpack
npm run start
# Откроется http://localhost:8080
```

### 4. Создайте production‑сборку
```bash
npm run build
```
